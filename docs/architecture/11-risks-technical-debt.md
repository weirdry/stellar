The renderer currently supports a two-level taxonomy and one-hop issue
neighborhoods. Its module is a deliberately retained SVG viewer, not a framework
migration. No independent consumer requires prototype JSON compatibility.
Unclassified context has no invented category; its radial ordering can differ
from the prototype's placeholder classification while relations are preserved.

There is no backend, live synchronization, shared runtime, or development
deployment. Do not infer capacity targets, migration obligations, or additional
release phases from these open items.
