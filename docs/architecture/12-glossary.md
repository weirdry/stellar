# 12. Glossary

State: **Target**

| Term | Meaning |
| --- | --- |
| Work map | Interactive representation of work classification and issue relationships |
| Primary classification | One purpose-based path assigned to each in-scope issue |
| Target tag | Cross-cutting subject shared by issues; distinct from the architecture state Target |
| Context issue | Issue outside the requested counting scope included to explain a relationship |
| Registered relation | Relationship explicitly recorded by the source system |
| Inferred association | Agent interpretation with stated provenance, not a source dependency |
| Work-map specification | Structured input consumed by the renderer; exact schema is Open |
| Bundled viewer | Reusable visual and interaction code shipped with the skill |
| Renderer | Tool that turns validated data and viewer resources into an artifact |
| Canonical | Authority for a concern, not proof of implementation |

Architecture and ADR state vocabularies are defined in the
[documentation index](../README.md).
