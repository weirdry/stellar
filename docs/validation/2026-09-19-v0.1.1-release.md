default branch and public tag separately with official `skills@1.7.0`, selecting
Codex and Claude Code. Each used Node 24.21.0, npm 11.19.0 and Git 2.39.5 from

The public-tag installation passed before publishing the GitHub Release. Each
installed canonical copy and Claude Code symlink was verified. The installer

## Installed workflow and preservation

Each installation passed **19 expected command outcomes** from an unrelated
temporary working directory. Runtime commands used the absolute Node executable
and an empty lookup environment, with only tracked invented fixtures:

- Help, normalization, issue/body inspection, bounded reading and literal search.
- First classification, capture retention, validation, rendering and all four
  `verify-run` comparisons; explicit state initialization also succeeded.
- User revision and refresh preserved user-owned classification. An agent
  overwrite attempt was refused; an allowed agent decision produced a verified
  final report with all four comparisons passing.
- Writing into an occupied run was refused. Original capture, initial and revised
  runs, final output after refusal and every installed file remained unchanged.
- The embedded base64 favicon decoded to the canonical Open Star SVG, and the
  inline header included its exact paths. This is executable identity evidence,
  not an additional perceptual browser review.

The first candidate probe incorrectly expected a percent-encoded favicon and
failed its probe assertion. The actual renderer uses base64. Correcting that
scratch decoder and rerunning in a fresh container passed; no product change or
failed attempt is counted as successful acceptance. Logs, receipts and probe
scripts remain in ignored `outputs/releases/v0.1.1/`.

## Limits

This is official installation plus synthetic command replay, not fresh Codex or
Claude Code invocation, automatic discovery or live collection. Firefox/Safari,
macOS/Windows installer acceptance and new manual image review were not performed.
Earlier [branding](2026-09-19-branding-pr.md) and diagram reviews apply to their
unchanged artifacts. Classification meaning is not approved by artifact checks.

Existing maintainer skill installations, reports, saved state and source systems
were not read or modified for acceptance. Reports outside an installed skill
remain outside the installer's replacement boundary. Remaining viewer work is
tracked in #16 and optional classification suggestions in #10. The publication
and installation results do not claim completion of those features.
