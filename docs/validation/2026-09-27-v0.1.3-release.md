## Scope

Stellar v0.1.3 delivers the completed maintained-source TypeScript conversion
and native-experiment source retirement from PRs #40 and #41. Core/CLI source,
all four JSON schemas, authored CSS/SVG and locale resources remain byte-identical
to v0.1.2. The viewer, tests and contributor tools now have strict TypeScript
owners; browser JavaScript is generated. Active measurement tools use Node TS
and optional system time. Completed native experiment source lives in Git
history, with original measurement datasets retained in the current tree.

The Git revision is the distribution artifact. No Stellar npm package, native
binary, service deployment or user report is published. This release does not
add compatibility readers or migrate saved state.
