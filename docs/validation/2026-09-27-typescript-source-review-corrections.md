# Maintained TypeScript source review corrections

Date: 2026-09-27

Scope: two P3 self-review findings on PR #40 at
`1242a92289db5e3246e6752c77d7f6c4c80a51de`. This follow-up changes contributor
checks, regression tests and documentation. Product code, generated delivery
artifacts, schemas, dependencies and archived experiments are unchanged.

## Root metadata discovery

The source inventory now applies its hidden-entry exclusion to root files as
well as nested directories. Synthetic `._eslint.config.ts`, `._extra.config.js`
and `._benchmark.py` sidecars no longer cause missing-source or legacy-source
failures. The regression also retains `viewer/._app.ts`, checks that the gate
leaves every file unchanged, and still rejects visible unchecked files and
incorrect Node/browser globals. Imported code remains checked by the compiler;
the discovery exclusion does not remove imported files from its programs.

## Localization source ownership

The fixed Korean copy check now scans authored viewer TypeScript recursively,
plus the authored shell and stylesheet. It no longer relies on generated
JavaScript, where esbuild escapes non-ASCII text. Locale key and interpolation
comparisons remain unchanged.

A synthetic regression builds a Korean literal with esbuild's ASCII output,
then plants that literal in the entry source, a nested TS helper, HTML and CSS.
Each authored-source violation must fail even though the generated script
contains no literal Korean characters. Source and generated bytes are preserved
by the check.

## Local evidence

Environment: macOS arm64, repository-pinned Node 24.19.0.

- Before correction, the added regressions both failed against the reviewed
  behavior: root metadata caused a coverage failure, and generated-only
  localization checking failed to reject the hardcoded source literal.
- After correction, the targeted catalog, hardcoding and maintained-inventory
  tests passed: 3/3, zero skipped. These tests run under the normal `just ci`
  gate; full commit-hook and hosted-CI outcomes are tracked separately in PR #40.
- The runner, viewer and manifest SHA-256 values still match the
  [original conversion record](2026-09-27-typescript-maintained-sources.md).

No product or browser behavior changed in this follow-up. Browser, benchmark,
profiling, installation, discovery, release and live collection were not rerun
as part of the targeted local verification. Earlier observations remain scoped
to their original revisions; this record does not promote them to new acceptance.
