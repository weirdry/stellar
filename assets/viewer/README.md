# Bundled viewer

State: **Target**

This directory will own the reusable HTML shell, CSS design tokens, SVG node
rendering, layout calculations, and browser interactions. The prototype source
has not been copied here.

Keep viewer source reusable across work-map inputs. Titles, source timestamps,
counts, classifications, and optional attachments come from data. Typography,
colors, node components, and interaction behavior come from this implementation.

See the [building-block view](../../docs/architecture/05-building-block-view.md).
